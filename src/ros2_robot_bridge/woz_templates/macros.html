Programmation avancée

Comment ça marche
  • Vitesse : de 0.1 (très lent) à 1.0 (pleine vitesse). Recommandé : 0.5.
  • Attente : secondes avant le mouvement suivant. Exemples : arc ≈ 3s, rire ≈ 6s, danse ≈ 8s.
  • Répétitions : 1× joue une fois. ∞ boucle indéfiniment jusqu'à ⛔ STOP.
  • Exécuter : lance la séquence immédiatement. Appuyez à nouveau pour arrêter.
  • Sauvegarder : donne un nom et crée un bouton permanent dans "Mes boutons".
